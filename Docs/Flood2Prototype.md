# Flood2 프로토타입: 마을을 지키는 물길

[기획·요구 명세](FloodStageDesign.md)의 시민 보호 규칙을 `Assets/Scenes/Flood2.unity`에 구현했다. 기존 `Flood.unity`와 스테이지 선택 목록은 유지했다. Flood2는 빌드 씬 목록에 등록되어 있으며, 현재 플레이 방법은 Unity에서 씬을 직접 열고 Play를 누르는 것이다. **Tools > Guard Wave > Open Flood2 Prototype** 메뉴로도 열 수 있다.

## 플레이

북쪽에서 들어오는 홍수가 분기 수로를 지나 남쪽으로 빠진다. 시장(A), 광장(B), 정류장(C)에 각각 시민 두 명이 있으며, 준비 시간 120초 동안 방벽을 세우거나 물길을 바꿔 여섯 명을 모두 지킨다. 시민은 직접 움직일 수 없다. 준비 완료 후 5초 경고가 끝나면 두 차례 홍수가 들어오고, 이때부터는 관찰만 가능하다.

| 조작 | 동작 |
| --- | --- |
| `1` / `2`, 왼쪽 클릭 | 방벽 패널 / 무거운 돌 설치. `Q`/`E`로 15°씩 회전, `Shift`를 누르면 격자 맞춤 해제 |
| `3`, 왼쪽 버튼을 누르고 이동 | 지면이나 자재의 접합면에 접합재 도포. 점 하나도 0.5m를 쓰므로 필요한 접촉부에 바른다. |
| `4`, 도포선 위에서 왼쪽 버튼 1초 유지 | 경화. 이미 연결된 접합은 2배로 강해지고 경화한 선에는 새 접합이 생기지 않는다. |
| `5`, 자재 클릭 / `Ctrl+Z` | 자재 회수 / 직전 편집 되돌리기 |
| `WASD`, 휠, 우클릭·중클릭 드래그 | 시점 이동, 확대, 회전, 화면 평행 이동. 왼쪽 구역 버튼으로 해당 구역, `Home`으로 전체 마을 보기. |
| `Enter` / `Esc` | 안내 시작·준비 완료 / 일시정지·재개 |

시작 재고는 패널 24개, 돌 18개, 접합재 30m다. 홍수 후에는 준비 완료 시점의 배치·재고·접합·경화 상태를 복원해 이어서 수정하거나 빈 배치로 새 시도를 할 수 있다.

## Inspector에서 수치 조정

Flood2 씬에서 `Flood2 - stage context`를 선택하면 스테이지와 건설 설정이 나온다. 카메라 설정은 카메라 오브젝트에 있다. Edit Mode에서 값을 바꾼 뒤 씬을 저장하고 새 Play Mode에서 확인한다. 이 문서의 수치는 초기 설정 기준이다.

| 컴포넌트 | 조정 항목 |
| --- | --- |
| `Flood2Stage` | 준비·경고·관찰·시도 제한 시간, 두 파도의 구간별 유입 수심과 지속 시간, 시민 샘플 주기와 공통 위험도 기준, 채널 초기 수위·유입·배수·마찰·수면 갱신 설정 |
| `Flood2Construction` | 시작 재고, 패널과 돌 크기, 배치 격자·회전 간격, 도포 비용·접합 반경·도포 한도, 경화 시간과 반경, 자재 밀도·저항 및 접합 파손 강도 |
| `Flood2Camera` | 전체 보기 위치·각도·배율, 시민 구역 확대와 카메라 조작 감도 |

시도 제한은 **준비 완료**부터 계산한다. 홍수 구간이나 관찰 시간을 늘릴 경우 경고, 유입, 관찰을 모두 마칠 수 있도록 이 제한도 확인한다. HUD의 홍수 예보와 재고·경화 표시도 Inspector 설정을 사용한다.

## 구현과 기획 대비 변경

- `Flood2Stage`가 준비·경고·홍수·평가와 결과를 제어한다. 각 시민 발 주변 5곳의 수심과 유속을 10Hz로 읽어 위험도를 갱신하며, 한 명이라도 위험도 100에 도달하면 실패한다. 유입 종료 후 최소 25초가 지나고 시민 전원이 5초 연속 안전하며, 시민 발 주변 잔류수도 3초 연속 안정되면 클리어한다. 수심 0.10m 이상에서 유속이 0.5m/s를 넘거나 최대 수심이 초당 0.10m보다 빠르게 오르면 아직 안정되지 않은 것으로 본다. 맵 전체 체적 비율을 쓰던 초기 판정에서는 시민을 지킨 뒤에도 하류의 배수 흐름이 실패를 일으켰다.
- `Flood2Water`는 0.6m 간격의 60×100 CPU 천수 격자에서 바닥 높이와 격자 경계 사이의 유량을 계산한다. 같은 물 데이터를 화면, 시민 관측, 자재의 부력·흐름 힘에 사용한다. 실제 자재 콜라이더를 격자에 반영해 물이 방벽을 돌아가거나 수위가 높으면 넘는다. 이 계산은 FLIP/APIC 또는 Eulerian Stable Fluids가 아니다. 물방울과 방벽 아래의 작은 틈, 구조물 위아래에 동시에 흐르는 물은 이 격자로 표현하기 어렵다.
- `Flood2Construction`과 `Flood2Piece`는 Rigidbody와 유한한 강도의 FixedJoint로 설치·파손·복원을 처리한다. 젖은 도포선을 주기적으로 확인해서 나중에 닿는 자재도 연결한다. 도포선마다 물리 트리거를 만들지 않는다. 기존 프로젝트의 중력 값은 유지하고 Flood2 자재에만 중력 가속도 9.81m/s²를 적용한다.
- 플레이 확인을 거쳐 상류 유입 입력의 두 고수위를 2.6m와 3.4m로, 준비 완료 후 시도 제한을 150초로 정했다. 유입표의 시각과 아래 검증 기록은 경고가 끝나고 유입이 시작된 때를 기준으로 한다.

## Unity Editor 확인 결과

| 조건 | 관측 결과 |
| --- | --- |
| 빈 배치 | 홍수 37.4초에 시장 A-2의 위험도가 100에 도달해 실패. 최대 수심 0.79m. |
| 세 구역에 경화한 방벽 4개씩 배치 | 홍수 57.0초에 시민 6명 전원 보호. 접합 12개 유지, 시민 지점의 최대 수심 약 0.05m, 위험도 모두 0. |
| 시장을 둘러싸고 광장·정류장은 사선 방벽으로 우회 | 방벽 8개·접합재 4m 사용. 홍수 85.1초에 시민 6명 전원 보호. 접합 8개 유지, 최고 수심 0.41m, 위험도 모두 0. |
| 세 구역 모두 사선 방벽만 배치 | 홍수 37.6초에 시장 A-2에서 실패. 광장과 정류장에서 통하는 배치가 시장에서는 부족했다. |
| 둘러싸는 배치로 재도전 | 방벽 12개와 경화한 접합 12개, 접합재 잔량 24m가 복원됨. 시민 위험도와 홍수 시간 초기화. 빈 배치로 시작하면 재고 24개/18개/30m로 복귀. |

둘러싸는 배치는 구역 중앙을 기준으로 상·하류에 패널을 하나씩, 양옆에 90° 회전한 패널을 하나씩 뒀다. 우회 배치는 상류에 ±30° 사선 방벽 두 개를 사용했다. 두 경우 모두 지면 접합을 경화했다. 돌 설치 후 도포로 접합이 생기고, 경화·도포·설치를 차례로 Undo하면 연결·도포선·재고가 복원되는 것도 확인했다.

검증은 Editor Play Mode에서 스테이지와 배치 기능을 직접 호출하는 방식으로 진행했다. 실제 키보드·마우스 조작을 처음부터 끝까지 수행하는 확인, 독립 실행 빌드, 목표 기기의 프레임 시간 측정은 별도 검증이 필요하다.
