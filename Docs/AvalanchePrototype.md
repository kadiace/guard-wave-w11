# Avalanche — 마을을 지키는 물길

눈사태 테마로 전환하기 전의 프로토타입이다. 현재는 홍수 경보 전에 물막이판과 모래주머니를 설치해 시장·광장·정류장의 시민 여섯 명을 지킨다. 시민은 각자의 위치에서 위험을 관찰한다. [초기 홍수 스테이지 기획](FloodStageDesign.md)

물막이판으로 주 흐름을 돌리고 모래주머니로 낮은 틈을 보강한다. 접합 블록을 지면이나 자재에 놓으면 닿는 자재가 고정된다. 물은 하류 경계로 흘러나간다.

## 플레이 흐름

1. Unity에서 `Assets/Scenes/Avalanche.unity`를 열고 Play를 누른다. **Tools > Guard Wave > Open Avalanche Prototype** 메뉴로도 씬을 열 수 있다.
2. 제한 시간 없이 시민 구역을 살펴보고 구조물을 설치한다.
3. 준비 완료 후 5초 경보가 울리면 편집이 잠긴다. 두 차례의 홍수가 진행되며 구역 목록에서 시민의 위험도를 확인할 수 있다.
4. 시민 한 명이라도 노출 위험도 100에 도달하면 실패한다. 유입 종료 25초 이후 전원이 5초 연속 안전하고 시민 주변 잔류수가 3초 연속 안정되면 성공한다.
5. 재도전하면 시민의 위험 상태를 초기화하고 준비 완료 전 자재·접합을 복원한다. `빈 배치로 새로 시작`은 자재 배치를 초기화한다.

| 조작 | 동작 |
| --- | --- |
| `1` / `2`와 왼쪽 클릭 | 물막이판 / 모래주머니 설치. `Q`/`E` 회전, `Shift`로 격자 맞춤 해제 |
| `3`과 왼쪽 클릭 | 지면 또는 자재 표면에 접합 블록 하나 설치 |
| `4`와 왼쪽 클릭 / `Ctrl+Z` | 자재나 접합 블록 회수 / 직전 편집 되돌리기 |
| 구역 이름 클릭 / `Home` | 구역으로 카메라 이동 / 전체 보기 |
| `WASD`, 휠, 오른쪽·가운데 버튼 드래그 | 이동, 확대, 회전, 화면 평행 이동 |
| `Enter` / `Esc` | 안내 시작·준비 완료 / 일시정지·재개 |

일시정지는 다른 스테이지와 같은 메뉴를 사용한다. 메뉴에서 계속하기, 빈 배치로 새로 시작, 스테이지 선택으로 돌아가기를 선택할 수 있다.

## 물리와 튜닝

- `AvalancheWater`는 0.6m 간격의 60×100 천수 격자로 흐름을 계산하고 하류 경계로 물을 내보낸다.
- `AvalancheConstruction`은 가볍고 높은 물막이판과 낮고 물보다 조밀한 모래주머니 두 종류를 제공한다. 기본 재고는 각각 24개와 18개다. 모래주머니 물리는 직육면체 콜라이더로 근사한다. HUD의 재고는 공통 스테이지 설정 값을 읽는다.
- 접합 블록은 기본 30개다. 자재에 놓은 블록은 자재를 따라가며, 나중에 닿은 자재도 연결한다. 연결 강도는 생성 즉시 파손 하중 9,000N과 5,200N·m를 적용한다. 자재마다 직접 맺는 연결은 하나이며, 파손된 연결은 자동으로 되살아나지 않는다. 블록을 회수하면 그 블록이 만든 연결이 풀린다.
- `Avalanche - stage context`에서 `AvalancheStage`의 관찰 시간과 유입 수심, `AvalancheConstruction`의 자재 치수·모래주머니 밀도를 조정할 수 있다. 준비 제한을 사용하려면 `Assets/Resources/Datas/StageInfo.json`의 Avalanche 항목에서 `limitPreparationTime`을 `true`로 바꾸고 `countdownSeconds`를 설정한다. 자재별 시작 재고도 같은 항목에서 설정한다. 휠 감도는 카메라의 `Stage Camera Controller > Camera Controls > Scroll Sensitivity`에 있다.

씬을 편집하는 동안 Inspector에서 각 컴포넌트의 설정을 조정할 수 있다. `AvalancheStage`는 파도별 수심과 지속 시간, 시민 위험 기준, 물의 유입·배수와 마찰을 제공한다. `AvalancheConstruction`에서는 배치 간격과 회전, 접합 블록의 접촉 반경, 물체의 밀도·저항과 접합 강도를 조정한다. `StageCameraController`에서는 전체 보기와 구역 확대, 카메라 조작 감도를 조정한다.

시도 제한은 준비 완료부터 계산한다. 홍수나 관찰 시간을 늘릴 때는 경고, 유입과 관찰을 모두 마칠 수 있도록 시도 제한도 확인한다. 화면의 홍수 예보와 재고 표시는 설정값을 따른다.

## 검증

아래는 대피·배수 지정 기능이 있었고 접합 블록을 도입하기 전의 과거 기록이다. 현재 구성의 플레이 결과로 사용하지 않는다. 시간은 경보가 끝난 뒤 유입이 시작된 시점부터 잰다.

| Unity Play Mode 배치 | 관측 |
| --- | --- |
| 시장에 대피팀, 광장에 배수팀, 정류장에 경화한 물막이판 4개와 모래주머니 1개 | 68.7초에 시민 6명 보호. 시장 2명이 대피대에 도착했고 광장 배수구에서 약 41.9m³가 하류로 빠졌다. |
| 같은 배치에서 시장 대피로를 물막이판으로 가로막고 광장 배수구를 모래주머니로 덮음 | 대피 중 구조물에 막히고 이후 대피로가 침수됐다. 배수량은 0m³였고 35.8초에 시장 시민 A-2의 위험도가 100에 도달했다. |
| 성공 배치에서 준비 상태로 복원 | 시장·광장 팀 배정과 자재 5개가 복원됐다. 대피 인원과 배수량은 초기화됐다. |

배치와 팀 지정은 에디터에서 플레이 함수를 호출해 확인했다. 수동 마우스 입력 전체와 플레이어 빌드 성능은 이번에 측정하지 않았다.

접합 블록을 도입한 뒤 Unity Play Mode에서 30개를 모두 쓰면 추가 설치가 거절되는지 확인했다. 지면의 블록에 나중에 닿은 물막이판은 9,000N과 5,200N·m의 강도로 연결됐으며, 물막이판에 놓은 블록도 다른 물막이판을 연결했다. 블록 회수 시 재고가 돌아오고, 되돌리기와 재도전 시 블록과 연결이 복원됐다.
