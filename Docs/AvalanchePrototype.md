# Avalanche — 눈사태에서 마을 시민 지키기

`Assets/Scenes/Avalanche.unity`는 산기슭 마을에 미리 배치된 시민을 두 차례의 눈사태에서 보호하는 프로토타입이다. 현재는 구성요소와 편집 흐름을 확정하는 단계이며, 클리어 전략과 난이도 검증은 후속 작업이다.

상세 규칙은 [눈사태 스테이지 명세](AvalancheStageDesign.md), 작업 상태는 [재구성 기록](AvalancheReconstructionStatus.md)을 참고한다.

## 구성과 진행

- 씬의 `Protected citizens` 아래 시민 6명이 저장되어 있다. 산장·광장·정류장에 각 2명이다. 플레이어는 시민을 배치하거나 회수하지 않는다.
- 팔레트에는 유도 방벽 12개, 하중 받침 10개, 접합 블록 18개가 있다. 재고는 `Assets/Resources/Datas/StageInfo.json`의 Avalanche 항목에서 읽는다.
- 제한 시간 없이 방어 구조물을 배치하고 준비 완료를 누른다. 5초 경보 이후 첫 눈이 내려오고, 재해 시간 12초에 두 번째 눈이 추가된다.
- 이동하는 눈과 쌓인 눈을 따로 계산한다. 첫 눈의 퇴적과 구조물 파손은 두 번째 눈에도 남는다.
- 시민 목록에서 적설, 충돌 노출, 연속 매몰 시간을 확인한다. 실패하면 구조물 배치를 복원해 수정할 수 있다. 빈 배치로 다시 시작해도 씬의 시민은 유지된다.

## 조작

| 조작 | 동작 |
| --- | --- |
| `1` / `2` / `3` | 방벽 / 받침 / 접합 블록 선택 |
| 왼쪽 클릭 | 미리보기 위치에 자재 생성 또는 표면에 접합 블록 설치 |
| 왼쪽 드래그 | 방벽과 받침 연속 배치 |
| `Q` / `E`, `Shift` | 자재 회전 / 격자 맞춤 해제 |
| 짧은 우클릭 | 선택 취소, 선택이 없으면 자재·접합 블록 회수 |
| 우클릭 드래그 | 카메라 이동 |
| 휠 / 우클릭 중 휠 | 확대·축소 / 카메라 회전 |
| `Ctrl+Z` | 자재·접합 편집 되돌리기 |
| 시민 이름 / `Home` | 해당 시민 보기 / 전체 보기 |
| `Enter` / `Esc` | 안내 닫기·준비 완료 / 선택 취소 후 일시정지 |

준비 완료 이후에는 구조물 편집을 잠근다. 안내·일시정지·결과 팝업은 다른 스테이지와 같은 UI를 사용한다.

## 씬과 Inspector 편집

| 대상 | 조정하는 값 |
| --- | --- |
| `Protected citizens/Citizen ...` | 고정 시민 위치와 `AvalancheCitizen`의 이름·구역·고유 번호·시각 참조 |
| `Avalanche - stage context > AvalancheStage > Citizens` | 보호할 씬 시민 참조 목록. 인원을 바꿀 때 목록도 함께 수정 |
| `AvalancheStage > Disaster timing / Snow releases` | 경보·방출·관찰 시간, 발원 중심·반경·초기 속도·부피 |
| `AvalancheStage > Citizens / Terrain and snow` | 시민 관측 주기·위험 기준, 지형 경사·골짜기, 눈 마찰·퇴적·하중·계산 설정 |
| `AvalancheConstruction` | 자재 치수, 배치 간격·회전·주기, 시민 여유 공간, 접합 반경·강도, 자재 질량·감쇠 |
| `Avalanche overview camera > StageCameraController` | 전체 보기, 시민 확대, 이동과 휠 감도 |

기본 방출량은 150/270m³, 매몰 두께는 0.35m다. 중단 전 비교 실행에서 조정한 임시 시작값이며 최종 난이도 확정값은 아니다. 시민은 지형 위와 눈 계산 영역 안에 놓는다. 런타임 지형은 Stage의 설정으로 생성하므로 경사를 바꿀 때 시민 발 높이도 맞춘다.

`Tools > Guard Wave > Set Up Avalanche Citizens`는 시민이 없을 때 기본 6명을 씬에 작성하고, 기존 시민이 있으면 위치를 보존한 채 Stage 참조를 등록한다. 자동으로 실행되는 기능은 아니다. 씬에서 원하는 위치를 직접 편집해 저장하는 것이 기본 작업 방식이다.

준비 제한시간은 기본적으로 사용하지 않는다. Avalanche는 씬에 고정 시민이 존재하면 준비 완료를 사용할 수 있으며, 다른 스테이지의 목표물 배치 규칙은 변경하지 않는다.
